# Library instructions

- Keep saved-for-later sources in `references/`, with author, URL, purpose, and source/reuse status. Saving a source does not adopt its style or create a skill.
- Keep created reusable capabilities in `skills/<name>/SKILL.md`, with standalone instructions, source attribution, limitations, and observable acceptance criteria. Index them under Created skills in README.md.
- Distinguish original workflow writing from copied or adapted external content. The repository license does not override external source terms.
- For visual scene design, read `skills/camera-movement-director/SKILL.md` after establishing dramatic intent and rough subject blocking, before finalizing storyboards, shot lists, animatics, or video prompts. Integrate its decisions into those artifacts and revisit affected shots when blocking or timing changes.
- Open library publication and account-level skill installation are separate states; report only verified installation and execution.

- Keep the landing page (`README.md`) bilingual in English and Simplified Chinese. Whenever its content changes, update both languages together so headings, descriptions, links, and contribution guidance convey equivalent information.
- 保持首页（`README.md`）的英文和简体中文双语内容同步。每次修改首页内容时，都应同时更新两种语言，确保标题、说明、链接及贡献指南表达一致的信息。
- When reporting changes, explicitly state whether they are local edits, locally committed, or pushed to GitHub. Remind the user when a push or merge is still needed for changes to appear on the public landing page; do not imply local changes are already published.
- 汇报修改时，明确说明内容是仅在本地修改、已在本地提交，还是已推送至 GitHub。如果仍需推送或合并才能显示在公开首页，请提醒用户；不要将本地修改描述为已经发布。
