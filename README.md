## Saving and adapting sources

For each reference, record the original URL, author credits, why it is useful, and the source license review. Keep external references distinct from personal adaptations and ready-to-use skills.

Check the source repository's license and relevant file-level and third-party notices before copying or adapting content. Preserve required copyright, license, and attribution notices. If permission is absent or unclear, save the link and original notes rather than reproducing the material. This repository's license does not override external authors' terms.
